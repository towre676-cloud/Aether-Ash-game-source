# Contributions, feedback and scope

Thank you for exploring Ash & Aether. Bug reports and accessibility notes are welcome via [GitHub Issues](https://github.com/towre676-cloud/Aether-Ash-game-source/issues).

Please identify whether your report concerns **the original ChatGPT Site**, **this public showcase**, or **the standalone Living World lab**. Those are different deployments. If reporting a bug, include reproducible steps, browser/device, any accessible error, and expected behavior. Do not share sensitive save data.

The project has **not yet selected a software or asset redistribution license**. No open-source license should be inferred from public GitHub visibility. Please ask the repository owner before reusing code, text, art or audio outside evaluation and permitted platform uses.
