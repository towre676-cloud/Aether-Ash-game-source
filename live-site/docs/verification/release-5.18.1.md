## Delivery and practical limits

The six original PNGs total 11,476,926 bytes; their six runtime WebPs total
3,330,790 bytes. Dimensions and alpha are unchanged; color compression is
lossy at quality 95. The original PNGs remain in the source archive.

Three older runtime PNGs were converted with the same dimensions and exact
alpha, reducing their combined size by 5,295,139 bytes. Their source originals
remain unchanged. All runtime consumers, including the dynamically assembled
URL in the older room-composition review, must use the new WebP paths.

The final world receipt records **260,721,676 expanded bytes** across 1,509
files, leaving **7,713,780 bytes** below the 256 MiB hosting gate. Its dependency
audit covers 137 modules with no missing imports or cycles. The source helper packages the exact pushed source when local packaging
can complete; a documented local packaging failure may use the native remote
build fallback without changing the source or Site audience.

New wall details and canopies render in both graphics modes. New facade and
roof pieces render in Standard; Compatibility keeps its prior facade renderer.
The five chapel walls, whole new facade assemblies, the staged river landing,
separate ground/grass/audio research and unfinished mount campaign are not
claimed as part of this delivery.

Browser review establishes visual fit and functional drawing, not a hardware
performance certification. The native successful deployment result verifies
publication. If the production URL shows the owner sign-in gate in the review
browser, matching local browser review remains distinct from authenticated
production gameplay testing.
