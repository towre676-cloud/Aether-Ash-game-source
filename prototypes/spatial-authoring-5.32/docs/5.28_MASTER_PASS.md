# Ash & Aether 5.28 — Moment-to-Moment Systems Pass

This package is an additive implementation bundle prepared against the verified 5.27 design state. It does **not** claim live deployment. The current chat has the Site projection but not the editable Site source/deployment capability, so the work is packaged and tested for merge into the authoritative host without replacing existing systems.

## 1. Transformative progression

### Weakness
A&A has a sophisticated Armory but too many upgrades still read as numeric improvements. A reward is most exciting when it creates a new play pattern immediately.

### Implemented
`src/progression.mjs` defines eight **verb mutations**, not percentage buffs:
- **Echo Step** — a perfect dodge stores a blink-flank basic attack.
- **Fault Chain** — breaking armor propagates a reduced fracture to nearby armor.
- **River Return** — water techniques leave a short healing/focus current.
- **Kiln Reversal** — guarding heavy physical impact stores heat for clay/ember.
- **Mossback Charge** — mounted encounter entry can smash light cover.
- **Hydrophone Lock** — matching hostile resonance delays an announced action.
- **Salvage Hook** — recover an enemy's dropped tool during combat and reuse it.
- **Aether Arc** — crossing charged ground leaves a damaging line.

`src/progression-reward.mjs` lets a victory surface up to three qualitatively different rewards: **gear**, **action mutation**, and **world unlock**. The intent is that the next fight feels different, not merely easier.

### Host rule
The host remains authoritative for actual technique resolution, inventory, equipment, currency and save transactions. The mutation layer decorates host actions and must be validated by existing battle rules.

## 2. Enemy identity and encounter variety

### Weakness
A large bestiary is not enough if enemies blur together into different stat/element combinations.

### Implemented
`src/enemy-identity.mjs` gives enemy archetypes a recognizable behavioral promise:
- gear thieves steal and flee;
- nest builders alter routes with debris;
- cover uprooters remove safe geometry;
- sound hunters pursue the loudest actor;
- shield weavers pull protection from nearby material;
- party splitters divide formations;
- mimic scavengers copy the last technique at reduced power;
- refuge raiders attack repaired world structures.

`src/encounter-director.mjs` varies objectives across defeat, interrupt, survive, extract, protect, route and disarm. It rejects immediate objective repetition and attaches enemy identities before the encounter begins, so the field silhouette, brief and battle can all describe the same threat.

## 3. Boss spectacle and phase variety

### Weakness
Guardians can have distinct moves yet still share the emotional rhythm of a normal fight with more HP.

### Implemented
`src/boss-catalog.mjs` assigns the 24 guardian chapters to eight phase families: resonance, ecology, gravity, flood, forge, memory, hunt and geometry. Each has a three-beat arena transformation, and chapters 9–24 revisit the family at greater intensity rather than repeating the same numbers.

Concrete examples in `src/boss-phases.mjs`:
- Bell Warden: resonant lanes → broken bells become cover → silence window exposes core.
- Orchard Colossus: root claims → canopy fall destroys/creates routes → seed shields can be broken for armor.
- Sky Engine: charged quadrants → push/pull reversal → overclocked final chain phase.

Boss phase changes are intended to mutate the **arena and available verbs**, not only damage tables.

## 4. Character animation and presentation

### Weakness
The environments have improved faster than character motion. Four-direction/few-pose movement and abrupt state changes make actors feel lighter than the world.

### Implemented
`src/animation.mjs` defines a small host-safe motion state machine: idle, turn-in-place, walk, run, airborne, mounted idle/run, action and recoil. Stride cadence, plant duration, body bob and forward lean scale with speed.

`src/character-presentation.mjs` selects expression and close-up intent from gameplay state and exposes visible equipment slots for the renderer. It preserves a stronger lead silhouette while companions stay readable without equal visual weight.

This is animation *logic*, not replacement art or rigs. Production animation clips still need to be authored/connected by the host renderer.

## 5. Exploration secrets and unscripted discovery

### Weakness
Guidance is useful, but if the best content is always marked, curiosity loses value.

### Implemented
`src/discovery.mjs` requires at least two different clue types before revealing a hidden discovery. Tracks alone do not produce a marker. Resonance + tracks, vegetation + geometry, weather + routine, etc. can cross a confidence threshold.

The returned discovery has `marker:false`: the host can give journal language or a world reaction without drawing a waypoint. This keeps Guided mode available while creating discoveries that belong to noticing the world.

## 6. Living world consequences and NPC routines

### Weakness
Many places still behave like sets waiting for the player even though A&A already tracks repairs, ecology, encounters and time.

### Implemented
`src/living-world.mjs` adds deterministic schedule classes for NPCs across morning/work/evening/night, plus festival/evacuation overrides. Repair, funding, neglect and raids change traffic, monster pressure, prices and state flags. Regional migration varies by region/day/weather.

Examples of intended host consequences:
- repairing a bridge increases traffic and reduces local monster pressure;
- neglect increases pressure;
- funding a trade project changes prices;
- a refuge raider can damage a repaired structure and reduce activity until restored.

## 7. Economy and side activities

### Weakness
Credits, scrap, essence and forging are functional but often feel like inventories of value rather than strategic choices.

### Implemented
`src/economy.mjs` introduces investment projects with explicit opportunity costs:
- river landing: new route, but consumes resources that could temper equipment;
- workshop press: cheaper future tempering, no immediate combat power;
- refuge signal: fewer ambushes but lower hunt-loot opportunity;
- market caravan: rotating rare stock with raid exposure.

Five side-activity loops are defined with different verbs and reward types: Hydrophone duel, Mossback trials, salvage sprint, creature tracking and weather-gated Bellrun variants.

## 8. Contextual UI simplification

### Weakness
A&A has accumulated enough systems that a universal menu can become a second game layered over the actual game.

### Implemented
`src/context-ui.mjs` ranks information by immediate consequence: danger > current action > reward > objective > nearby > status > lore. The contextual action bar is capped at five actions and only surfaces verbs relevant to the current state.

This complements 5.26's field-label limits: less information is removed from the game, but much less competes at once.

## 9. Physical traversal continuity

### Weakness
Some map changes still feel like state switches rather than traversing a continuous place.

### Implemented
`src/transitions.mjs` creates short transition plans from existing geometry: door movement, stairs, river landing, camera bridge and entry. The transition preserves heading and aims for sub-second continuity rather than a cinematic interruption.

The unresolved art brief from earlier sessions—real river landing geometry and interior partitions—fits directly into this interface.

## 10. Mobile and long-session verification

### Weakness
Automated browser tests do not reveal heat, battery drain, thumb fatigue or physical-device frame pacing.

### Implemented
`src/mobile-audit.mjs` checks minimum touch target sizes, p95 frame time, pinch-scale jitter and a conservative pixel-ratio recommendation. It deliberately fails tiny samples with a 24 ms spike instead of averaging the hitch away.

### Still not automatable here
A true 30–60 minute Android play session on a physical device remains a human/device task. The instrumentation can record local measurements, but it cannot substitute for a person noticing fatigue or boredom.

## Measuring whether the game became more fun

`src/fun-metrics.mjs` keeps **local-only** session measurements (no network transmission): action variety, repeated-action ratio, optional encounter rate, whether a reward is equipped within two minutes, whether it is used in the next encounter, voluntary detours and discovery yield.

These are not a "fun score." They are indicators for the specific problems we identified. The useful question is whether the player is voluntarily varying actions, using rewards, and leaving the guided path because the world made them curious.

## Save safety

`src/save-migration.mjs` creates a namespaced `save.moment` record without changing existing chapter, inventory, world, NG+ or character fields. Migration is idempotent at version 1 and is covered by tests.

## Integration ownership

The package must not create a second:
- movement loop;
- camera;
- combat resolver;
- inventory/equipment system;
- terrain/grass simulation;
- audio engine;
- save file;
- NG+ timeline.

`src/host-adapter.example.mjs` demonstrates callback wiring into the authoritative host event bus.
