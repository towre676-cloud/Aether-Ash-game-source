# Source provenance and claims

## This public showcase

The homepage, its illustrated cover and documentation are new presentation assets authored for the repository. **The cover is an illustration, not a screenshot of the deployed game.**

## Standalone playable lab

The version preserved as `labs/living-world.html` originates from the recovered Library artifact **reconciliation-lab-offline.html** (82,786 bytes, source artifact available in the project collection), itself part of the Living World / grass reconciliation effort. It is a self-contained HTML+JavaScript test environment, with no network dependency.

The broader **Ash_Aether_Living_Atlas_v8_Spatial_Encounters.zip** archive contains a project structure with `index.html`, encounter/evolution work, production stagers, source modules, images and receipts. It identifies the environment and encounter engine as **standalone and playable**, **not** integrated into the canonical ChatGPT Site.

The original game is recorded under Site project `appgprj_6adf63724e5c8191bd55637b8ecd8d9a`, slug `ash-aether-clay-water`. In its published text projection dated 2026-10-31, the Site reports **5.42 · Surface and shadow** and displays its campaign acts, choice of character, overture and 3D dungeon entry.

Other recovered work includes **Ash_Aether_Living_Armory_v3_Complete.zip**, **AA_Acoustic_World_v4.zip**, **Ash_Aether_5.32_Spatial_Authoring_3D_Pass.zip**, **Ash_Aether_5_37_Environment_Production_Upgrade.zip**, and **Ash_Aether_5_37_Production_Integration_Modules.zip**. These files must be checked against a current editable game-source export before being represented as one merged runnable game.

## What's not mirrored

The repository is **not currently a full export of the Site**. The current Live Site source, original sound masters, full playable campaign and all archive members are not claimed to be present. Links to private ChatGPT Library archives have deliberately not been presented as public-download URLs.

## Future verification rules

For a release claim, specify the tested commit/version, the accessible build URL, device/browser checks, runtime assertions and a confirmed source-to-release link. For demo screenshots label *gameplay capture*, *development lab* or *illustration* distinctly. Do not silently replace the canonical runtime with an old prototype.
